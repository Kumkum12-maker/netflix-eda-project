# netflix-eda-project

Overview
This project is a simple exploratory data analysis (EDA) of Netflix titles using Python libraries such as Pandas, Matplotlib, and Seaborn. The dataset includes details about movies and TV shows available on Netflix as of 2021.

Dataset
Source: [Netflix Titles Dataset on Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
File Used : `netflix_titles.csv`

Objectives
- Understand the distribution of movies and TV shows
- Analyze top content-producing countries
- Explore trends in content release years
- Visualize most common genres on Netflix
- Extract deeper insights like average movie durations and most active directors
  
Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Key Insights
- Majority of Netflix content is Movies
- United States and India are among the top content-producing countries
- Content has increased significantly over recent years
- Drama, Comedy, and Documentaries are among the most frequent genres
- Some directors have more than 10 titles featured on Netflix
- Average movie duration is around 90–100 minutes
- Some TV shows run for over 10 seasons
